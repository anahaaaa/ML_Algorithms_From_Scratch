# 🌟 ML Algorithms From Scratch

A collection of Machine Learning algorithms implemented completely from scratch using Python and NumPy.

This repository focuses on understanding the mathematical intuition and internal working of machine learning models instead of relying entirely on high-level libraries.

---

# 🎯 Goal

The main goal of this repository is to build a strong understanding of Machine Learning fundamentals by implementing core algorithms manually.

This project helps in:

* Understanding how ML algorithms work internally
* Learning optimization techniques like Gradient Descent
* Building Neural Networks from scratch
* Visualizing predictions and learning patterns
* Strengthening NumPy and Python fundamentals

---

# 📂 Algorithms Included

## 📈 Linear Regression

Implementation of Linear Regression using Gradient Descent.

### Concepts Covered

* Mean Squared Error (MSE)
* Cost Function
* Gradient Descent
* Prediction Line Visualization
* Learning Rate Optimization

---

## 📊 Logistic Regression

Implementation of Logistic Regression for binary classification tasks.

### Concepts Covered

* Sigmoid Function
* Binary Classification
* Cross Entropy Loss
* Decision Boundary
* Gradient Descent

---

## 📉 Polynomial Regression

Implementation of Polynomial Regression for modeling non-linear relationships.

### Concepts Covered

* Polynomial Features
* Curve Fitting
* Feature Transformation
* Model Complexity

---

## 🧠 Two Layer Neural Network

A fully connected Two Layer Neural Network implemented completely from scratch using NumPy.

### Features

* Forward Propagation
* Backpropagation
* Weight Initialization
* Activation Functions
* Neural Network Training
* Loss Computation

# ▶️ Running the Project

## Clone the Repository

```bash

```

## Navigate to Project Folder

```bash

```

